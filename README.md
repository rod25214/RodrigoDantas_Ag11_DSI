# RodrigoDantas_Ag11_DSI

# 💧 Controle de Níveis de Água

## 📌 Descrição do Projeto

Este projeto foi desenvolvido para a atividade Ag11_DSI do curso Técnico em Desenvolvimento de Sistemas.

O programa simula um sistema de monitoramento de um reservatório de água, exibindo mensagens coloridas no terminal de acordo com o nível de água. Para isso, utiliza a linguagem Python e a biblioteca Colorama.

## 🎯 Objetivo

Desenvolver um programa simples que identifique diferentes níveis de água e apresente mensagens de alerta com cores específicas, facilitando a visualização da situação do reservatório.

## ⚙️ Tecnologias Utilizadas

- Python
- Biblioteca Colorama

## 🌊 Níveis do Reservatório

| Nível | Situação | Cor |
|---|---|---|
| 1 | Muito baixo (crítico) | Vermelho |
| 2 | Baixo | Amarelo |
| 3 | Médio | Verde |
| 4 | Alto | Ciano |
| 5 | Muito alto (alerta) | Azul |

## 🚀 Como Executar o Projeto

### 1. Instalar o Python

É necessário ter o Python instalado no computador. O download pode ser feito pelo site oficial:

https://www.python.org/downloads/

### 2. Instalar a biblioteca Colorama

Abra o terminal na pasta do projeto e execute o comando:

```bash
pip install colorama
```

### 3. Executar o programa

Execute o seguinte comando no terminal:

```bash
python seuNome_Ag11_DSI.py
```

Substitua `seuNome` pelo nome utilizado no arquivo Python.

## 🧠 Conceitos de Programação Aplicados

- Listas para armazenar as situações do reservatório.
- Funções para organizar e reutilizar o código.
